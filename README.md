# sechick.github.io

Personal homepage for Stephen E. Chick — Professor of Technology and Operations
Management at INSEAD. A single, self-contained `index.html` (no build step, no
dependencies) hosted on GitHub Pages.

## Live site

https://sechick.github.io

## Editing

Everything is in `index.html`. Open it in any browser to preview locally, edit
the content/styles inline, and commit. Publications, cases, and contact details
are plain HTML near the bottom of the file and are easy to update.

## Deploying

1. Push changes to the `main` branch.
2. GitHub Pages rebuilds automatically (Settings → Pages → Deploy from branch, `main` / root).
3. Changes appear at https://sechick.github.io within a minute or so.

## Custom domain (optional)

Add a `CNAME` file containing your domain, then configure the DNS records shown
in Settings → Pages.
